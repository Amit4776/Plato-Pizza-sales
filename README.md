# Plato-Pizza-sales Analysis in Excel dashboard
## Project Overview 
  This project analyzes pizza sales data using Microsoft Excel.
The dashboard was created to monitor business performance, identify sales trends, analyse customer ordering behaviour, and discover top-performing pizza categories and sizes.

The project transforms raw sales data into interactive visual insights using Excel dashboards, Pivot Tables, charts, and KPI metrics.

## Business problem
  The objective of this project is to help a pizza business:

 - Track overall sales performance
 - Identify best-selling and low-selling pizzas
 - Analyze customer ordering patterns
 - Monitor monthly revenue trends
 - Understand pizza category and size preferences
 - Support business decision-making through data visualization

 ## Dataset Information
 Click here for Dataset -  [Maven Pizza Challenge](https://mavenanalytics.io/challenges/maven-pizza-challenge)
 
 The dataset contains one year of pizza sales transaction data, including:

- Order date and time
- Pizza categories and sizes
- Quantity sold
- Revenue details
- Product information

## Business Questions Addressed
  - How many orders are placed each day?
  - What are the peak ordering hours?
  - Which pizzas generate the highest revenue?
  - Which pizza sizes are most popular?
  - What are the monthly sales trends?
  - Which pizza categories perform best?
  - Which products need improvement or promotion?

  -Monthly sales trends

 ## Key Insights
  - Large pizzas generated the highest sales volume.
  - Evening sessions recorded the highest number of orders.
  - Classic category contributed the largest share of sales.
  - Thai Chicken Pizza was the top-selling pizza by revenue.
  - Sales peaked during mid-year months.
