# Plato-Pizza-sales Analysis in Excel dashboard
## Project Overview 
  This project analyzes pizza sales data using Microsoft Excel.
The dashboard was created to monitor business performance, identify sales trends, analyse customer ordering behaviour, and discover top-performing pizza categories and sizes.

The project transforms raw sales data into interactive visual insights using Excel dashboards, Pivot Tables, charts, and KPI metrics.

## Business problem
  The objective of this project is to help a pizza business:

 - Track overall sales performance
 - Identify best-selling and low-selling pizzas
 - Analyze customer ordering patterns
 - Monitor monthly revenue trends
 - Understand pizza category and size preferences
 - Support business decision-making through data visualization
